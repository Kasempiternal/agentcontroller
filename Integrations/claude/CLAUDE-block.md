## AgentController — operate this Mac yourself (MUST while it is connected)
- When `mcp__agentcontroller__*` is connected, you do the on-screen work yourself, in the background, with the user's saved logins: get values and keys from dashboards, create and copy keys, fill forms, click through consoles and settings, finish CLI/OAuth logins in the browser (`wrangler login`, `codex login`, `gh auth login --web`, MCP OAuth), reply in desktop apps, check iPhones and simulators (`mcp__agentcontroller-ios__*`). Never hand the user a step you can do: no "open this page", "paste the key", "click Allow", "send me the URL", "check the phone". The `agentcontroller` skill has the playbooks.
- Load the tools in ONE ToolSearch call (`select:mcp__agentcontroller__open_url,mcp__agentcontroller__snapshot,mcp__agentcontroller__run_steps,mcp__agentcontroller__read_all_text,mcp__agentcontroller__click,mcp__agentcontroller__type_text,mcp__agentcontroller__screenshot_window`) and try them first. Then: one `snapshot`, one `run_steps` for the whole sequence. Fall back to claude-in-chrome or Playwright only when AgentController demonstrably cannot do the step.
- Never take focus: no `activate_app`/`foreground:true`, no shell `open` without `-g` (pages go through `open_url`), no `osascript` activate/keystroke, no `open -a Simulator`, no `bringToFront()`. A PreToolUse hook enforces the shell part; `# agentcontroller:allow-focus` only when the user asked to see something in front.
- Ask the user only when genuinely blocked: a login with no saved session, 2FA or captcha, a secret that exists nowhere you can read, a payment or legal acceptance, an irreversible action nobody authorised, or something that needs their ears or hands. Ask once, with the page already open in the background, naming the single thing to do.
- Server shows failed or the tools are missing: run `open -g -j /Applications/AgentController.app` and `~/.agentcontroller/bin/agentcontroller install-claude --check`; tell the user in one line if the session needs a restart to reattach. Never fall back to having them do the step by hand.
- The user's other hard rules (which accounts/credentials to use, prices, Apple ID web sessions) still win over this block.
